# Updated Product Roadmap (Post-Validation)

**Change:** Deprioritized Desktop UI, Prioritized Mobile Web Optimization.
**Reason:** 70% of traffic and 85% of conversions came from mobile during Experiment 01.

## Revised Plan

### Sprint 1 (Next 2 Weeks)
- **Focus:** Mobile-first Frontend & Basic Database
- **Deliverable:** Read-only mobile view of library occupancy (manual updates).
- **Changes:** Removed "Admin Dashboard" from Sprint 1 to focus on mobile experience.

### Sprint 2
- **Focus:** Spotter Interface (Data Input)
- **Deliverable:** Secure way for students to update occupancy counts.

### Deferred
- Desktop-specific features are pushed to Sprint 4.
